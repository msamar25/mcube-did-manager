# v50 — Operator permissions

Operator accounts have access to Dashboard, Analytics, Request, and Report, including manual DID replacement, bulk operations, request review, and reports. Settings navigation and settings/credential APIs remain administrator-only.

Inventory snapshot clearing and employee/history sync are operational actions available to operators. Confirmation prompts and all existing queue/replacement safety checks remain active.

Use the existing OPERATOR_EMAIL / OPERATOR_PIN_HASH or OPERATOR_USERS_JSON environment variables.
